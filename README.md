# 🌤️ Weather Dashboard

A responsive weather application built using HTML, CSS, and JavaScript. It allows users to search for weather information in different cities and view current weather conditions along with a 5-day forecast.

## ✨ Features

- City Search: Search for weather information by entering a city name.
- Current Weather: View temperature, humidity, wind speed, and feels-like temperature.
- 5-Day Forecast: Check upcoming weather conditions and daily temperature ranges.
- Live Location: Get weather information based on your current location.
- Favourite Cities: Save frequently searched cities.
- Local Storage: Keep favourite cities saved even after refreshing the page.
- Dark Mode: Switch between light and dark themes.
- Responsive Design: Works on mobile phones, tablets, and desktops.
- Error Handling: Displays messages when a city cannot be found or weather data cannot be loaded.

## 🛠️ Technologies Used

- HTML5 – Application structure.
- CSS3 – Styling and responsive layout.
- JavaScript – Application functionality.
- Fetch API – Fetching weather data.
- Open-Meteo API – Weather information and forecasts.
- Geolocation API – Detecting the user's location.
- Local Storage – Saving favourite cities and theme preferences.

## 🌐 API Used

This project uses the free Open-Meteo API to retrieve weather information.

- "Open-Meteo Weather API" (https://open-meteo.com/)
- No API key is required.
